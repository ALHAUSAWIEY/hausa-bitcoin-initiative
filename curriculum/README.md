Hausa Bitcoin Initiative (HBI)

Bitcoin Education Curriculum

Overview

This curriculum provides a structured learning pathway for Hausa-speaking learners who want to understand Bitcoin, its underlying technology, security principles, and open-source ecosystem.

The curriculum is designed for beginners and progressively introduces technical concepts through practical activities.

Learning Levels

Level 1: Bitcoin Fundamentals

Objective: Understand what Bitcoin is and how its basic systems work.

Lessons:

1. Introduction to Bitcoin
2. History and Origin of Bitcoin
3. How Bitcoin Works
4. Cryptography and Hashing in Bitcoin
5. Bitcoin Wallets and Self-Custody
6. Bitcoin Transactions and Fees
7. Bitcoin Mining and Proof of Work
8. Bitcoin Nodes and Decentralization
9. Bitcoin Security and Common Scams
10. Bitcoin and Financial Freedom

Level 2: Technical Understanding

Objective: Develop a deeper understanding of Bitcoin's technical architecture.

Planned topics:

- Bitcoin protocol and consensus rules
- UTXO model and transaction structure
- Bitcoin Script fundamentals
- SegWit and transaction formats
- Lightning Network fundamentals
- Running and configuring a Bitcoin full node
- Bitcoin Core architecture
- Bitcoin network privacy

Level 3: Open-Source Contribution

Objective: Help learners participate meaningfully in the Bitcoin ecosystem.

Planned topics:

- Understanding open-source development
- Git and GitHub fundamentals
- Reading technical documentation
- Reporting bugs and proposing improvements
- Reviewing and translating documentation
- Introduction to Bitcoin Core contributions
- Community collaboration and peer review

Practical Learning

Learners will be encouraged to:

- Explore public Bitcoin transactions using blockchain explorers.
- Understand wallet security and self-custody.
- Study Bitcoin network and node operations.
- Read official technical documentation.
- Practice using GitHub to contribute to educational resources.
- Participate in collaborative translation and review.

Learning Principles

1. Accuracy: Technical explanations should be supported by reliable references.
2. Accessibility: Materials should be understandable to Hausa speakers.
3. Practicality: Learning should include demonstrations and exercises.
4. Security: Responsible wallet and network practices are essential.
5. Openness: Resources should encourage transparent collaboration.

- "Bitcoin Developer Documentation" (https://developer.bitcoin.org/)
- "Bitcoin Core GitHub Repository" (https://github.com/bitcoin/bitcoin)
- "Bitcoin Optech" (https://bitcoinops.org/)

Curriculum Development

This curriculum is a living educational resource. Lessons and technical materials will be reviewed and improved as the project develops.

Contributions from Hausa translators, Bitcoin developers, educators, and researchers are welcome.
